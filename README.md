# Apex - Premium AI SaaS Landing Page

A world-class, production-ready AI SaaS landing page built with Next.js, React, Tailwind CSS, and Framer Motion. Designed to look similar in quality and professionalism to Stripe, Vercel, Linear, Notion, Framer, and Raycast.

## 🎯 Project Overview

This is a complete premium landing page for an AI-powered SaaS platform featuring:

- **Modern Design**: Clean, elegant, professional aesthetic
- **Fully Responsive**: Mobile-first design optimized for all devices
- **Smooth Animations**: Sophisticated animations powered by Framer Motion
- **Premium Components**: Reusable, well-structured React components
- **Dark Theme**: Modern dark color scheme with gradient accents
- **Production-Ready**: Optimized performance, proper TypeScript, SEO-friendly

## 🏗️ Features Implemented

### 11 Complete Sections:
1. **Navbar** - Sticky navigation with mobile menu & scroll blur effect
2. **Hero** - Premium hero with dashboard mockup & dual CTAs
3. **Trusted By** - Company logo wall section
4. **Features** - 6 premium feature cards with icons
5. **Dashboard Preview** - Large interactive dashboard showcase
6. **Benefits** - Before/after comparison with statistics
7. **Pricing** - 3 tiers with monthly/yearly toggle
8. **Testimonials** - 6 customer testimonials with ratings
9. **FAQ** - Accordion-style questions with smooth animations
10. **Final CTA** - Powerful call-to-action section
11. **Footer** - Multi-column links with newsletter signup

## 🎨 Design System

- **Colors**: Dark backgrounds (#0b1120), indigo/blue accents, white text
- **Typography**: Poppins (headings) + Inter (body)
- **Spacing**: Consistent 24px section padding
- **Effects**: Smooth gradients, subtle glows, professional shadows
- **Animations**: Framer Motion with fade-up, stagger, hover effects

## 🛠️ Technology Stack

- **Framework**: Next.js 16.2.6 with App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS 4
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Build**: Turbopack

## 🚀 Getting Started

```bash
# Development server
npm run dev

# Production build
npm run build

# Start production
npm start
```

Visit **http://localhost:3000** to view the landing page.

## 📝 Customization

### Change Brand Name
Edit `app/components/Navbar.tsx` and `app/components/Footer.tsx`

### Update Colors
Modify `app/globals.css` `:root` variables

### Edit Content
- Features: `app/components/Features.tsx`
- Pricing: `app/components/Pricing.tsx`
- Testimonials: `app/components/Testimonials.tsx`
- FAQ: `app/components/FAQ.tsx`
